# YapdOme v0.2

Локальный сервер: `python3 -m backend.server` из корня проекта (Python 3.10–3.13).
На macOS также доступен `START.command`. Порт по умолчанию — 13180;
его можно переопределить переменной `TRIAD_PORT`.

## Авторизация ChatGPT (Sign in with ChatGPT)

YapdOme использует официальный open-source flow OpenAI: динамическую регистрацию клиента,
PKCE, стабильный `ext_agent_host_id` и локальное хранение токенов с правами владельца.
Имя приложения при регистрации — `YapdOme`.

**Важно о бесплатном тарифе:** вход в ChatGPT и разрешение использовать лимиты ChatGPT —
разные права. Текущий flow запрашивает `chatgpt.tokens.use.direct` для генерации ответов.
По опубликованным правилам OpenAI, использование лимитов в open-source приложениях доступно
подходящим аккаунтам Plus/Pro; аккаунт Free не может рассчитывать на это разрешение.
Изменение кода приложения не может включить недоступное разрешение или обойти лимиты.
При отказе YapdOme показывает объяснение, а не бесконечно повторяет вход.

Официальные документы:
- [OpenAI: интеграция Sign in with ChatGPT для open-source приложений](https://developers.openai.com/cookbook/articles/sign-in-with-chatgpt)
- [OpenAI: open-source flow и регистрация клиента](https://developers.openai.com/siwc/token-sharing-open-source/sign-in)
- [Условия Sign in with ChatGPT](https://openai.com/policies/sign-in-with-chatgpt-terms/)

Токены сохраняются локально в `~/.triad-dialogue/accounts.json`; каталог и файл защищаются
правами доступа пользователя. Не публикуй этот файл и не отправляй его в issue.

## OpenAudio S1-mini — локальная озвучка

1. Открой голосовую студию и выбери **OpenAudio S1-mini**.
2. Выбери отдельную папку модели и нажми **Установить / подключить**.
   Установщик автоматически подготовит изолированное окружение Python, закреплённую
   версию Fish Speech и скачает официальные веса `fishaudio/openaudio-s1-mini`.
   Для загрузки нужны Git и доступ к GitHub, PyPI, PyTorch и Hugging Face.
   Файлы весов проверяются по размеру и SHA-256 из метаданных Hugging Face LFS.
3. Дождись готовности: она подтверждается загрузкой модели и пробным синтезом.
   Рекомендуется NVIDIA GPU с 12 ГБ VRAM. Без CUDA используется CPU;
   загрузка и генерация могут быть медленными. Ускорение Apple MPS не используется.
4. Без референса модель сама выбирает голос. Для постоянных голосов загрузи
   до трёх референсов: PCM WAV 16 бит, моно или стерео, 3–30 секунд, до 6 МБ,
   и точную расшифровку. Затем выбери референс в карточке каждого персонажа.
   WAV и расшифровка сохраняются локально в папке модели.

Синтез работает локально и не требует Fish Audio API или API-ключа.
Установку можно отменить и повторить; уже скачанные файлы переиспользуются.
Для S1-mini по умолчанию используется обычная HTTPS-загрузка без Xet,
с частыми обновлениями прогресса и поддержкой возобновления. Готовые файлы
переиспользуются и проверяются; при неверной SHA-256 файл один раз скачивается
заново. Это также позволяет восстановиться после прерванной сборки файла Xet.
Ошибки установки и запуска доступны в `install.log` и `worker.log` в папке модели.
Скорость речи меняется локально с сохранением высоты голоса.

### Если Hugging Face сообщает «Cannot access gated repo»

Для скачивания нужно один раз разрешить доступ на Hugging Face и войти
на том Mac, где запущен YapdOme. В панели S1-mini есть раскрывающаяся
инструкция «Как разрешить скачивание S1-mini — пошагово» с готовой командой
для выбранной папки модели. При этой ошибке инструкция раскрывается автоматически.

1. Открой [страницу модели](https://huggingface.co/fishaudio/openaudio-s1-mini).
   Нажми **Log In** или **Sign Up** и войди в аккаунт.
2. Прочитай условия модели и нажми кнопку согласия или запроса доступа.
   Если запрос ожидает одобрения, дождись разрешения.
3. В том же аккаунте открой [Access Tokens](https://huggingface.co/settings/tokens).
   Нажми **Create new token**, выбери **Read**, задай имя `YapdOme` и создай токен.
   При выборе Fine-grained в разделе Repositories включи
   **Read access to contents of all public gated repos you can access**.
   Скопируй созданный токен.
4. На Mac нажми **⌘ + пробел**, введи **Терминал** и нажми Enter.
   Вставь команду из панели S1-mini и нажми Enter. Для стандартной папки это:

   ```bash
   "$HOME/Library/Application Support/YapdOme/openaudio-s1-mini/venv/bin/hf" auth login
   ```

5. Когда Терминал попросит токен, вставь его и нажми Enter.
   Символы могут не отображаться — это нормально.
   На вопрос **Add token as git credential?** ответь `n` и нажми Enter.
6. После сообщения об успешном входе вернись в YapdOme и повтори установку.

Если выбрана другая папка, используй готовую команду из панели приложения.
Если Терминал пишет `No such file or directory`, сначала запусти установку:
она создаст окружение Python и клиент `hf`.
Токен вводится только в Терминале: не отправляй его в чат и не вставляй в поле папки.
Авторизация сохраняется стандартным клиентом Hugging Face и используется
установщиком автоматически. API-ключ Fish Audio не нужен.

Если вход завершился `Login successful`, но загрузка всё ещё запрещена,
открой Access Tokens → YapdOme → Edit permissions, включи указанное выше
разрешение на public gated repos и сохрани. Убедись также, что доступ аккаунта
к модели одобрен. После изменения прав того же токена повтори установку;
повторный вход обычно не требуется. Если создал новый токен, выполни вход с ним.

Веса S1-mini распространяются по **CC BY-NC-SA 4.0**;
см. [официальную модель](https://huggingface.co/fishaudio/openaudio-s1-mini)
и [закреплённую версию Fish Speech](https://github.com/fishaudio/fish-speech/tree/781bf1cd7afef831fc58928a6444a2161449dae5).

## Донаты

Донаты в интерфейсе пока являются локальным тестом. Сумма меньше 100 даёт
пять реплик по сообщению зрителя. От 100 включительно ИИ проверяет, можно ли
использовать сообщение как новую тему: при одобрении она заменяет текущую
тему разговора, при отказе или ошибке проверки сообщение обсуждается пятью
репликами. Донаты обрабатываются по очереди после завершения текущей озвучки.

## Проверки

```bash
python3 -m unittest discover -s tests -v
node --test $(rg --files tests -g '*.js' -g '!test_dashboard_layout.js')
```

Проверка раскладки требует Playwright, Chromium и запущенного сервера:
`node tests/test_dashboard_layout.js http://127.0.0.1:13180`.
Тесты OpenAudio используют локальные фикстуры и не скачивают веса.
